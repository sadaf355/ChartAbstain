STEP 1 NOTES - Platform recon (AutoScientist Challenge, Entry A)
Items marked (confirm) are not yet checked on the platform itself.

1. BASE MODEL
   AutoScientist can tune Gemma, Qwen, GPT-oss, Llama, Mistral, Mixtral and
   NVIDIA Nemotron models. All support SFT and DPO, with LoRA or full
   fine-tuning depending on the model.
   Chosen model ID: Qwen/Qwen3.5-9B   (confirm exact ID in the model dropdown)
   Minimum training rows: 1,000 (our train set has 1,970).

2. UPLOAD FORMAT
   Both input/output JSONL (data/train.jsonl) and chat format
   (data/train_messages.jsonl) are accepted.
   Raw mode: processing_mode="raw" with column_mapping
   {"prompt": "input", "completion": "output"} for train.jsonl.
   Chat data can use the chat column.
   DECISION (confirm, then never change): ________
   Rule: if train.jsonl (no system prompt) is used, add --no_system to every
   predict run, base and tuned.

3. IMAGES
   Platform supports multimodal training via an image column, but multimodal
   datasets cannot be augmented and need about 20,000+ rows. We are
   text-only (charts described as text).
   Limit to state in write-up: if the held-out test uses chart images,
   text-only training may transfer less well. (ask in Discord)

4. HELD-OUT WIN RATE
   Field: best_win_rate (best result across iterations).
   Shown in the dashboard under "Training Winrates" (adapted vs base model),
   and via API: client.autoscientist.get(run_id).best_win_rate
   Shown for every completed run (confirm).

5. CONCURRENT RUNS AND CREDITS
   Parallel runs allowed (distinct idempotency_key or run IDs).
   Max iterations per run: 1-5 (default 3).
   Total credit budget: not stated in docs. Check the dashboard balance.
   Preview cost first with datasets.run(..., estimate=True).
   Seed budget: decide after seeing cost of run A0.
   Ablation subsets: 1,000 and 1,500 rows (500 is below the minimum).

6. CALLING THE TUNED MODEL / DOWNLOADING WEIGHTS
   No hosted endpoint. Download the LoRA adapter:
     with client.autoscientist.with_streaming_response.download(run.id) as r:
         r.stream_to_file("best-checkpoint.tgz")
     tar xf best-checkpoint.tgz -C best-checkpoint
   Contents: adapter_config.json, adapter_model.safetensors, tokenizer.json,
   trainer_state.json
   Inference: Colab T4 GPU, 4-bit base model + peft adapter
   (scripts/predict_local.py --adapter best-checkpoint).
   Together AI is not free, so it is not used.
